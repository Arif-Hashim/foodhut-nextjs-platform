# FoodHut — Multi-Vendor Food & Home-Chef Ordering Platform (Next.js + MongoDB + JWT)

## Quick Start in VS Code
1. Extract this zip archive and open the `foodhut-nextjs-platform` folder in **VS Code**.
2. Open the VS Code Terminal (`Ctrl + ~`) and install packages:
   ```bash
   npm install
   ```
3. Add your MongoDB Atlas URI in `.env.local` (the app also works immediately in fallback demo mode if you run it before adding your MongoDB URI).
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open `http://localhost:3000` in your browser.
